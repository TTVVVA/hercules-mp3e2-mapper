Dica: no Modo layout, arrasta os pontos para alinhar com a foto. A configuração fica guardada no browser.

Passos

  1. A app abre com o esquema Mixxx da MP3 e2 e hotspots por botao/knob/fader.
  2. Clica no hotspot certo e configura a funcao.
  3. Se quiseres, usa "Calibracao exata" para ajustar qualquer controlo.

Áudio independente

A transmissão CABLE fica a 100%. O Windows faz a cópia estável para os auscultadores; esta app ajusta apenas o volume que ouve.

A preparar os dispositivos de áudio…

Primeiro use Usar CABLE como saída geral. Depois, no Windows: Som > Mais definições de som > Gravação > CABLE Output > Propriedades > Ouvir, ative Ouvir este dispositivo e escolha os Corsair. O Discord deve usar o botão privado acima. No Parsec, desligue Echo Cancelling. Não inicie uma segunda rota de monitorização.
